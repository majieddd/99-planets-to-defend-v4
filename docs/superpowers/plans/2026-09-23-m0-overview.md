# M0 Overview: Foundations and Style Check

> **For agentic workers:** this file indexes four implementation plans. Execute each with
> superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Read
> `docs/blueprint.md` first; its pillars and Build order item 1 must be restated before any task.

**Goal:** everything milestone M0 of `docs/blueprint.md` requires: a checked, tested, deployed
TypeScript and three.js workspace; the pure simulation kernel; the Blender 5.2.1 asset pipeline with
the style-scene assets; and the Painted-Anime-Inkline 4.0 renderer shown in the Style Lab for the
owner's style gate.

## Environment facts every task relies on

- Node 24 (`node --version` prints v24.x). npm 11.
- TypeScript is pinned to **6.0.3**: typescript-eslint 8.70 supports `>=4.8.4 <6.1.0`, and TypeScript 7
  no longer ships the classic compiler API it needs.
- three is pinned to **0.186.0** and postprocessing to **6.39.5** (its peer range is `>=0.168 <0.187`).
  The painted material includes r186 shader chunks, so upgrading three is its own task with a visual
  regression check.
- Blender 5.2.1 LTS is found through `BLENDER_PATH`. On the owner's machine:
  `C:\Users\Majied LaFleur\tools\blender-5.2.1\blender.exe`. Verified facts: Python 3.13 and numpy 2.3
  are bundled; actions are slotted (no `action.fcurves`), so poses are keyed with
  `pose_bone.keyframe_insert`; `export_animation_mode='ACTIONS'` exports every action stashed on an
  NLA track; a float mesh attribute named `_ink` exports as `_INK` with `export_attributes=True`;
  Cycles EMIT bakes into a shared atlas across several selected objects; Workbench renders textured
  previews with outlines; OptiX sees the RTX 4080.
- Blender quirk found in the spike: changing the colour space of a generated image after writing its
  pixels regenerates it to black. Write PNG files with the pure-Python writer in `blender/lib/png.py`
  and load them.

## Conventions for every plan

- No em dash anywhere: the character, `&` + `mdash;`, `&#` + `8212;`, or the backslash-u escape.
  `npm run check` fails on any of them.
- Commit messages: a subject line, then prose describing what changed, why, and the measurement.
  End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- "Done" means a result line or a frame that shows the behaviour. Paste the command output into the
  task's review.
- Update `docs/blueprint.md` (Decided, Task list, Where we are) in the same commit that changes the
  game.

approve are written into `src/render/defaults.ts` as Painted-Anime-Inkline 4.0 and recorded in the
blueprint's Decided ledger with the frame paths as evidence.
